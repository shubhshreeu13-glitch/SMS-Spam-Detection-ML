# SMS Spam Detection Using Machine Learning

## Project Overview
This project uses Machine Learning to classify SMS messages
as Spam or Ham (Normal messages).

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Machine Learning Algorithm
- TF-IDF Vectorization
- Multinomial Naive Bayes

## Dataset
SMS Spam Collection Dataset.

## Model Accuracy
97.94%

## Features
- SMS message classification
- Spam probability prediction
- Confusion matrix visualization
- Dataset distribution visualization

## Project Files
- SMS_Spam_Detection_ML.ipynb
- SMS_Spam_Detection_Project.pdf

## Conclusion
The trained model can identify spam and normal SMS messages
using Natural Language Processing and Machine Learning.
